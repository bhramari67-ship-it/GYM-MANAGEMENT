# Gym Management - Project Statement

## Problem Statement
Small gyms often keep member details, attendance, and payment records manually. This can make searching records and calculating simple summaries difficult.

## Scope
This project provides a beginner-level command-line system for storing gym member details, recording attendance, recording payments, and viewing a simple gym summary.

## Target Users
- Small gym owners
- Gym reception staff
- Students learning basic Python programming

## High-Level Features
1. Add and view members
2. Search and remove a member
3. Mark and view attendance
4. Record and view payments
5. Display a basic gym summary
